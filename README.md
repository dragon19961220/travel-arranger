# 旅遊行程規劃工具

一個單一 HTML 檔的行程規劃網站，不需要伺服器、不需要安裝，打開就能用。

## 功能

- 填入**出發日期**和**回程日期**，自動展開每一天（Day 1、Day 2…，含星期）
- 每天固定有**早餐、午餐、晚餐**，另外可以自由**新增行程**
- 每個項目都有：時間（選填）、名稱、簡單介紹、**預算**、**實際花費**；列表只顯示重點，點一下行程會跳出編輯視窗
- **費用分攤**：任何項目都能選要平均分攤到哪幾天（例如雪具租借分到滑雪的那幾天）；住宿可直接填入住／退房日，自動分攤到每一晚
- **拖拉行程**到別天或行前區；手機可在編輯視窗用「日期」選單和「上移／下移」調整
- **手機版**：上方有 D1、D2… 日期列可快速跳到某天，下方有固定工具列（匯出 PDF、備份、匯入、回到頂部），點行程會從下方滑出編輯面板
- 可設定主要幣別和一種外幣＋匯率（例如 1 TWD = 4.5 JPY），自動換算加總
- **行前／不分日的費用**區塊：機票、住宿、保險、網卡等
- 費用總覽：總預算、實際花費、剩餘預算、每人平均
- 費用統計：**每日花費**、**分類花費**（交通、餐飲、體驗、住宿、購物、伴手禮、醫美、保險、其他）、每日 × 分類明細，可切換看「實際花費」或「預算」；PDF 也會附上統計表
- 項目可上下移動、依時間排序；每天可收合
- **Google 地圖**：每個行程旁的 📍 會用 Google 地圖搜尋該地點；航路圖裡可一鍵用 Google 地圖開啟整天路線
- **航路圖**：每天標題旁的「🧭 航路圖」會把當天地點畫成復古航海圖（上北下南、羅盤、虛線航線、比例尺），起點是前一晚住宿、終點是當晚住宿；也有全程航路圖，PDF 會一起印出。座標可貼上 Google 地圖座標或自動查詢（OpenStreetMap）
- **匯出 PDF**：點「匯出 PDF」後，在列印視窗選「另存為 PDF」
- 資料自動存在瀏覽器（localStorage）；可「下載備份」成 JSON，換電腦或分享時再「匯入備份」

## 放上 GitHub Pages

1. 在 GitHub 建立一個新的 repository（例如 `trip-planner`）
2. 上傳 `index.html` 和 `README.md`
3. 到 repository 的 **Settings → Pages**
4. Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾選 `/ (root)`，按 Save
5. 等一兩分鐘，網址會是 `https://<你的帳號>.github.io/trip-planner/`

## 注意

- 資料只存在使用者自己的瀏覽器，不會上傳到任何伺服器；清除瀏覽器資料會一起清掉，記得定期下載備份。
- 每個人打開同一個網址，看到的都是自己的資料。

## 座標怎麼來？（航路圖用）

在行程的編輯視窗，於「📍 Google 地圖」欄填入**地標名稱或地址**（例如「カムイスキーリンクス」或「北海道旭川市神居町西丘112」），停止輸入約 1 秒後會自動抓取座標：

- **沒有設定金鑰**：用免費的 OpenStreetMap 查詢。大型景點、車站、地址通常查得到，小店可能查不到。
- **有設定 Google 地圖金鑰**：改用 Google 地圖查詢，準確度和 Google 地圖一樣。

座標可以隨時手動修改（也可以貼上 Google 地圖網址）。手動改過的座標會標示「手動輸入」，之後改地標名稱也不會被覆蓋；想重新抓就按「重新抓取」。

### 申請 Google 地圖金鑰（選填）

1. 到 [Google Cloud Console](https://console.cloud.google.com/) 建立一個專案，並依指示綁定帳單帳戶（Google 地圖平台要求綁定，有每月免費額度）。
2. 在「API 和服務 → 程式庫」啟用：**Maps JavaScript API**、**Geocoding API**、**Places API (New)**。
3. 到「API 和服務 → 憑證」建立 **API 金鑰**。
4. 編輯這把金鑰，務必設定限制：
   - 應用程式限制：選「網站」，加入 `https://你的帳號.github.io/*`
   - API 限制：只勾上面三個 API
5. 建議到各 API 的「配額」頁設定每日上限，避免意外產生費用。
6. 回到網站，在「01 旅程設定 → 進階：Google 地圖金鑰」貼上金鑰。

金鑰只會存在使用者自己的瀏覽器，不會寫進網站檔案，也不會放進「下載備份」的 JSON。
